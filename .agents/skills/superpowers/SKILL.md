# Superpowers Workflow Guide

This skill grants advanced pair-programming capabilities to design, build, test, and optimize features rapidly with expert precision.

---

## 1. Architectural Design & Feature Scaffolding
- **Blueprint First**: When starting a complex feature, sketch the module layout, component dependencies, and data flow before implementation.
- **Clean Architecture & Separation of Concerns**: Keep business logic decoupled from presentation layers, storage providers, and external services.
- **Defensive API Design**: Validate input parameters, handle boundary conditions, and use explicit error types.

---

## 2. Deep-Dive Debugging & Root Cause Analysis
- **Empirical Diagnostics**: Inspect full error tracebacks and console output before making changes.
- **Root Cause Fixes**: Fix the core architectural flaw or state violation rather than suppressing errors or masking symptoms.
- **Regression Guard**: Write targeted test cases covering identified bug paths to prevent future regressions.

---

## 3. High-Efficiency Code Generation & Refactoring
- **Idiomatic Patterns**: Follow language-specific conventions, standard formatting, and modern idioms.
- **Modular Components**: Write focused, single-responsibility functions and classes.
- **Performance Awareness**: Avoid redundant database queries, unbounded collection iterations, and unnecessary main-thread blocking operations.

---

## 4. Quality Assurance & Test Scaffolding
- **Comprehensive Test Coverage**: Add unit, integration, and edge-case tests for new functions.
- **Deterministic Mocks**: Mock external network calls and slow dependencies in automated test suites.
- **Automated Verification**: Run tests, linters, and type-checkers to verify all edits before completion.
