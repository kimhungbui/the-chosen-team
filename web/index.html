🛡️ Python Deterministic Guardrail Layer (The Method 4 Difference)

Core Innovation

While standard LLM tools (Method 2) output grades based on generic prompt "vibes", Method 4 introduces a non-LLM Python post-processing layer:

  • Verbatim Substring Search: Programmatically validates whether quotes exist character-for-character in the original documents.
  • Line Number Resolution: Scans character offsets to generate clickable line references (e.g. rfp_nordframe.md:L17).
  • Mathematical Score Locking: Binds the Completeness score strictly to the compliance percentage formula: Score = 1.0 + 4.0 * (Met + 0.5 * Partial) / Total.
  • Fix Enforceability: Programmatically checks that suggested fixes are full, formatted draft paragraphs rather than generic advice.
